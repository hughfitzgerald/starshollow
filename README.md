# Stars Hollow Showdown

A Gilmore Girls-themed Visual Pinball X table, built with [GLF](https://github.com/mpcarr/vpx-glf) (Game Logic Framework).

Flip your way through Stars Hollow — chase multiball at Luke's, rack up jackpots, and see if you can out-talk Lorelai and Rory to the high score table.

---

## Features

- Multiball with physical locks and stealable locks from other players
- Skill shot, kickback, and extra ball modes
- Hurry-up modes via spinner and ramp shots
- Magnet, diverter, and drop target shots
- Animated B2S backglass and alphanumeric DMD
- Gilmore Girls callouts and music
- Godot-powered media display

## Getting Started

Open `starshollow.vpx` in Visual Pinball X. See the [GLF Environment Setup Guide](https://mpcarr.github.io/vpx-glf/environment-setup/) if you're setting up VPX or GLF for the first time.
