# Stars Hollow Showdown

A Gilmore Girls-themed Visual Pinball X table, built with [GLF](https://github.com/mpcarr/vpx-glf) (Game Logic Framework).

Flip your way through Stars Hollow — chase multiball at Luke's, rack up jackpots, and see if you can out-talk Lorelai and Rory to the high score table.
